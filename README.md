# RISE v14 — Final Pre-Server Edition

نسخه آماده‌سازی پیش از اتصال به سرور: بازطراحی آیکون‌های اصلی رابط کاربری، جداسازی مسیرهای ناوبری، و رفع نمایش تب‌های نامرتبط در پنل‌ها.

- آیکون‌های SVG اختصاصی برای نوار منابع، داک پایین، منوی کناری و دکمه‌های نقشه
- بیمارستان، سربازخانه و فرماندهان ارشد هرکدام صفحه مستقل دارند
- فروشگاه و قبیله از یکدیگر جدا هستند
- گفتگوی قبیله صفحه اختصاصی دارد و دیگر به تب‌های پیام‌رسان تزریق نمی‌شود
- پیام‌رسان، رتبه‌بندی، فصل و امپراتوری از مسیرهای مستقل باز می‌شوند

## اجرا و تست

```bash
npm run check
```

این نسخه همچنان از ذخیره‌سازی محلی استفاده می‌کند و شامل بک‌اند/پرداخت/همگام‌سازی چنددستگاهی نیست؛ اتصال به سرور مرحله بعدی پروژه است.
